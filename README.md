O CineLista é uma aplicação web desenvolvida como projeto acadêmico para a disciplina de Desenvolvimento Front-end para Web da faculdade.
O objetivo é oferecer um catálogo de filmes onde os usuários podem pesquisar títulos, filtrar por gênero e organizar seus filmes favoritos.

Acesso à aplicação
 (https://gabriel29x11-code.github.io/CineLista/)

Funcionalidades
- Catálogo de filmes
- Pesquisa por título
- Filtro por gênero
- Sistema de favoritos
- Visualização de detalhes dos filmes
- Gráfico de avaliações

Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
